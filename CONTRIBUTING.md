# Contributions

DecAustrum is source-available for portfolio evaluation and is not an open-source
project. External code contributions are not currently accepted.

Please do not submit pull requests, patches, or files for incorporation into the
project. This policy preserves a clear intellectual-property chain while
DecAustrum is being evaluated as both a portfolio project and a possible
commercial product. A contribution may be considered in the future only under
a separate written contributor agreement.

General feedback may be left through GitHub when the repository owner enables
the relevant feature, but it creates no support, maintenance, confidentiality,
or response obligation. Potential vulnerabilities should not be disclosed in a
public issue; follow [SUPPORT.md](SUPPORT.md) instead.
